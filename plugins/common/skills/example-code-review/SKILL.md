# Example Code Review

This is an example capability, not production policy.

When reviewing a change:

1. State the intended behavior in one sentence.
2. Check correctness, regression risk, tests, and error handling.
3. Prefer concrete findings with file and symbol references.
4. Separate confirmed defects from optional improvements.
