Treat `teamai-learnings` as the only V4 published Learning source in this Git repository. The Marketplace resource `main` branch carries the catalog, Plugins, instructions, `manifest/projects.yaml`, and contexts; a file there is not a published Learning and must not be read as a fallback.

Refresh from an exact fetched commit and validate the complete snapshot before advancing the current pointer. A missing branch, fetch or authorization failure, invalid path or file type, or hash mismatch is an error, not an empty Learning set. Keep the last-good snapshot and existing owned projections when refresh fails. Remove an owned projection only after a successfully validated complete snapshot confirms that its source file is absent.

Source: [V4 Spec #14, F06](https://github.com/teamai-vault/teamai-cli-copilot/issues/14) and [Marketplace contract #8](https://github.com/teamai-vault/teamai-marketplace/issues/8).
