接入你已有的工作方式

下次，只多做这两件小事。

pr

准备交 PR 时，把 diff 和验证材料交给它。

审阅结果：变化看得懂，证据查得到，风险说得清。仓库已有模板时，明确要求兼容。
retro

一次返工之后，指定那次会话让它回看。

从记录追到建议，优先选一项。已有检查失效时，先修好或接通它。

已安装时可点名「使用 pr skill」或调用 /retro；具体入口取决于客户端。无需把现有实现流程换成整套 Matt 工作流。
