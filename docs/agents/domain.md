# Domain docs

This repo uses a single-context layout: `CONTEXT.md` at the root and ADRs in `docs/adr/`.

Before exploring a feature, read the relevant `CONTEXT.md` terms and ADRs if those files exist. Their absence does not block work; create them when domain terms or decisions need to be recorded.

Use the glossary's terms in issues, code discussions, and tests. Surface any conflict with an existing ADR explicitly.
